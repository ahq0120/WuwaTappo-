# Wuwa Tappo 自動領寶箱 v1.1.2

1. 點選 **Code → Download ZIP**，下載後完整解壓縮。
2. 開啟 Wuwa Tappo 並登入，讓桌寵顯示在桌面。
3. 雙擊 `start.bat`，保留執行視窗。
4. 首次辨識時先關閉表情及設定面板，等兩個寶箱都可以領取。
5. 辨識完成後，每 5 秒檢查並自動背景領取，可以照常玩遊戲或使用電腦。

適用 Windows 10／11，不需要安裝 Python。請將 `start.bat`、`wuwa_live.ps1`、`NativeBackground.cs` 放在同一個資料夾。

辨識完成後可以開啟表情；無法確認寶箱時會暫停，條件恢復後自動繼續。更改桌寵大小或重開桌寵後，請關閉面板並等待兩個寶箱就緒，以重新辨識。

操作桌寵時會暫停領取，切回遊戲或其他視窗後繼續，並顯示恢復提示。兩顆就緒時會先上方、再下方，通常間隔約 7～8 秒。若另一顆暫時無法點擊，會持續重查，最多等待 60 秒；最後一顆領完後約 20 秒才完成本輪等待，期間桌寵可能暫時無法取得焦點。若領取後按鈕未消失，程式會停止，請確認桌寵狀態後再啟動。

按 Ctrl+C 停止。請勿同時執行舊版。若意外強制關閉後桌寵操作異常，完整退出 Wuwa Tappo 再開啟。

若執行視窗被滑鼠選取後停住，按 Esc 解除選取，並在視窗內容中關閉「快速編輯模式」。

若需回報問題，請附上同資料夾產生的 `wuwa-live-日期時間.log`；其中會記錄領取過程及前景程式名稱。若出現 `Cannot update Wuwa window style`，可對 `start.bat` 按右鍵，選「以系統管理員身分執行」後重試。
