# Wuwa Tappo 寶箱自動領取

## 使用方式

1. 按 **Code → Download ZIP**，下載後先解壓縮。
2. 開啟 Wuwa Tappo，保持桌寵可見，關閉背包、設定等面板。
3. 在 `start.bat` 按右鍵，選擇 **以系統管理員身分執行**。
4. 每次啟動，先等 **兩個寶箱都可領取**，不要手動領取。腳本會從三顆按鈕中找出兩顆同尺寸的寶箱並記住尺寸。
5. 看到「已自動辨識寶箱尺寸」後，就會每 5 秒檢查並依序領取；之後只有一個寶箱出現也能領取。請保持命令列視窗開啟。
6. 按 **Ctrl+C** 或關閉命令列視窗即可停止。

- 支援 Windows 10/11 內建 Windows PowerShell，不需要安裝 Python、Git 或其他套件。
- `start.bat` 和 `wuwa_live.ps1` 必須放在同一個資料夾。
- 桌寵位置可以移動。調整桌寵大小或螢幕縮放後，腳本偵測到尺寸／介面變化會重新辨識；請再等兩個寶箱都可領取。若沒有重新辨識，停止並重開腳本。
- 尺寸只記在這次執行中，重新啟動腳本需要再次等待兩個寶箱。
- 不要同時執行其他自動開箱工具。開箱仍會正常扣除點擊數。
- 若腳本停止，請查看原程式是否有點擊數不足、網路錯誤等提示；確認後再重新執行。

### 只檢查、不領取

在 CMD 執行下列指令，將路徑換成實際檔案位置：

```bat
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "完整路徑\wuwa_live.ps1"
```
